# LegacyExodus Community Code of Conduct

LegacyExodus is committed to providing a welcoming, inclusive, and harassment-free community environment for all contributors and participants.

The project officially adheres to the **[Contributor Covenant Code of Conduct](../../CODE_OF_CONDUCT.md)** (Version 2.1).

---

## Canonical Policy

Please refer to the authoritative **[CODE_OF_CONDUCT.md](../../CODE_OF_CONDUCT.md)** in the repository root for the full text, standards of behavior, enforcement responsibilities, scope, and impact guidelines.

## Reporting Incidents

To report any conduct violations or inappropriate behavior, please open an issue or communicate directly with repository maintainers via the canonical project repository channels. All reports are handled with confidentiality and investigated promptly.
